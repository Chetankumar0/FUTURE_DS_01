# Data

The raw dataset is **not committed** to this repository (it is ~48 MB and belongs to its original publisher).

**Download:** <https://www.kaggle.com/datasets/ulrikthygepedersen/online-retail-dataset>
(free Kaggle account required).

1. Download and unzip `archive.zip`.
2. Place the file here as `data/online_retail.csv`.
3. Run `notebooks/01_sales_performance_analysis.ipynb`.

**Columns:** `InvoiceNo`, `StockCode`, `Description`, `Quantity`, `InvoiceDate`, `UnitPrice`, `CustomerID`, `Country`
**Size:** 541,909 rows · **Period:** 1 Dec 2010 – 9 Dec 2011
